# apoyar.eu website

Static site served by Netlify project `apoyar-eu` (https://apoyar-eu.netlify.app).

- `public/` is the published folder (see `netlify.toml`)
- `public/_redirects` holds legacy-path redirects
- `legacy_v1/` is the previous site, kept for reference (not deployed)
- `done.md` records the September 2026 overhaul

The previous repo contents (Railway/Express variant, privacy and cookies pages, white paper, GitHub-stats function) are preserved on branch `archive/pre-mirror-2026-11-24`.
